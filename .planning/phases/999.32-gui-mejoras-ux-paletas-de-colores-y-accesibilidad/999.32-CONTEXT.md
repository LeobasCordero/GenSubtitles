# Phase 999.32 — Context: GUI Mejoras UX, Paletas de Colores y Accesibilidad

**Gathered:** 2026-04-28
**Status:** Ready for planning

<domain>
## Phase Boundary

7 mejoras UX/accesibilidad en la GUI de 6 tabs:
1. Auto-populate de nombres de archivo en cadena (Tab 1 y Tab 3)
2. Deshabilitar todos los botones de acción/browse/clear durante procesos activos
3. Separador visual en consola al inicio de cada proceso nuevo
4. "Limpiar campos" borra la consola del tab activo (toggle en Settings)
5. Fix de contraste del texto en botones secundarios
6. Sistema de paletas de colores con predefinidas + editor por token (panel separado en Settings)
7. Traducción de mensajes de consola/log según idioma activo

</domain>

## Implementation Decisions

### D-01: Filename Auto-populate — Cadena desde Tab 3

Al seleccionar un video en **Tab 3 (Extraer Audio)** se propaga el nombre en cadena:
- Tab 3 output: `{stem}.wav`
- Tab 4 input: `{stem}.wav`
- Tab 4 output (placeholder): `{stem}.json`  ← solo si Tab 4 no tiene valor (ver D-01b)
- Tab 5 input: `{stem}.json`
- Tab 5 output (placeholder): `{stem}_translated.json`
- Tab 6 input: `{stem}_translated.json`
- Tab 6 output (placeholder): `{stem}.srt`

**Tab 1 (Generate Subtitles)** ya funciona: `_browse_input()` línea ~1534 auto-llena `_output_var` con `{stem}.srt`. No requiere cambio.

**D-01b: Sobreescritura** — Siempre sobreescribir todos los campos al seleccionar nuevo video, incluso si el usuario ya había escrito algo. Garantiza consistencia del stem en toda la cadena.

**D-01c: Directorio de salida** — Mismo directorio que el video de entrada. Si la configuración tiene un `default_output_dir`, usarlo como base en lugar del directorio del video.

**D-01d: Vars afectadas:**
- `_extract_output_var` → `{stem}.wav`
- `_transcribe_input_var` → `{stem}.wav`
- `_transcribe_output_var` (si existe) → `{stem}.json` ← verificar si este var existe en main.py
- `_translate_step_input_var` → `{stem}.json`
- `_translate_step_output_var` (si existe) → `{stem}_translated.json` ← verificar
- `_write_input_var` → `{stem}_translated.json`
- `_write_output_var` → `{stem}.srt`

El agente debe verificar cuáles de estos vars existen y cuáles no tienen StringVar de output.

### D-02: Button Locking Durante Procesos Activos

**Scope:** Todos los botones de acción primaria + Browse/Save as + Clear en TODOS los tabs se deshabilitan mientras `_job_active` es True (o análogo por tab).

**Botones a deshabilitar (lista exhaustiva):**
- Tab 1: `_btn_generate`, `_btn_clear`, `_btn_browse_input`, `_btn_browse_output`
- Tab 2: `_tl_btn_translate` (si existe), Browse de Tab 2
- Tab 3: botón "Extract Audio", botón Clear, `_extract_btn_browse_input`, `_extract_btn_browse_output`
- Tab 4: botón "Transcribe", botón Clear, browse de Tab 4
- Tab 5: botón "Translate", botón Clear, browse de Tab 5
- Tab 6: botón "Write Subtitle", botón Clear, browse de Tab 6

**Mecanismo:**
- Crear método `_set_all_action_buttons(state: str)` que configure todos los botones listados.
- Llamar `_set_all_action_buttons("disabled")` al inicio de cualquier proceso largo.
- Llamar `_set_all_action_buttons("normal")` al completar (éxito o error) usando `self.after(0, ...)`.
- Usar el mecanismo `_job_active` existente para evitar que Tab 1's `_on_generate` se llame dos veces.
- Para tabs 3-6, el disable/enable envuelve `_run_step_in_bg()`.

**Nota:** La condición de re-habilitación de Tab 1 `_btn_generate` ya depende de `_server_ready` y de si hay campos llenos. Usar el método `_update_generate_state()` existente al re-habilitar, en lugar de forzar "normal" directamente.

### D-03: Separador Visual en Consola

Al inicio de cada proceso nuevo (antes del primer mensaje de log), insertar una línea separadora:

```
══════════════════════════════════════════════════
```

- Usar `═` (U+2550) repetido 50 veces.
- El separador se inserta via `_log_to()` antes del mensaje de inicio del proceso.
- **Clave de locale:** `"log_separator"` → `"═" * 50` (igual en en y es — es un separador visual).
- Se agrega en cada `_on_tab3_extract`, `_on_tab4_transcribe`, `_on_tab5_translate`, `_on_tab6_write`, `_on_generate`, y `_tl_on_translate` al inicio.

### D-04: Clear Fields + Console Toggle

**Nuevo campo en `AppSettings`:**
```python
clear_console_on_clear: bool = False
```

**Settings panel** — nueva fila después del campo "Directorio de salida predeterminado":
- Label: `s("clear_console_on_clear_lbl")` → "Clear console on Clear fields" / "Limpiar consola al limpiar campos"
- Widget: `CTkSwitch` (on/off)
- Se guarda en `settings.json` al hacer Save.

**Comportamiento en `_on_clear()` y equivalentes de tabs 3-6:**
- Si `self._current_settings.clear_console_on_clear` es True:
  - Borrar el contenido del CTkTextbox de log del tab activo (solo ese tab).
- La consola del tab activo se identifica por qué tab está visible (`self._tabview.get()`).

**Método helper:** `_clear_console(textbox: CTkTextbox)` — configura state=normal, delete("1.0", "end"), state=disabled.

### D-05: Secondary Button Text Color — Fix de Contraste

**Problema:** `apply_secondary_btn_style()` en `styles.py` no fija `text_color`. En Light mode el bg es `#E0E0E0` (gris claro) y el texto por defecto de CTk puede ser gris oscuro → bajo contraste.

**Fix:** Agregar `text_color` explícito en `apply_secondary_btn_style()`:
```python
def apply_secondary_btn_style(widget: object) -> None:
    widget.configure(
        fg_color=p("secondary"),
        hover_color=p("secondary_hov"),
        text_color=p("btn_secondary_text"),   # nuevo token
    )
```

**Nuevos tokens en `_PALETTES`:**
```python
"Dark":  { "btn_secondary_text": "#E0E0E0" }   # texto claro sobre gris oscuro
"Light": { "btn_secondary_text": "#212121" }   # texto oscuro sobre gris claro
```

Esto también se extiende al sistema de paletas (D-06).

### D-06: Sistema de Paletas de Colores

#### Arquitectura

**Nuevo panel** accesible desde `Settings > Color Palette…` (nueva entrada en el menú Settings).

**Paletas predefinidas (6):**
| Nombre | Modo | Descripción |
|--------|------|-------------|
| Default Dark | Dark | Paleta actual oscura (azul/gris) |
| Default Light | Light | Paleta actual clara |
| Ocean Dark | Dark | Azul profundo + cyan |
| Emerald | Dark | Verde esmeralda sobre oscuro |
| Sunset | Light | Naranja/rosa cálido sobre claro |
| Monochrome | Dark | Solo grises + blanco |

**Tokens editables (todos los de `_PALETTES` + `btn_secondary_text`):**
`bg`, `surface`, `input_bg`, `text_primary`, `text_secondary`, `accent`, `accent_hov`,
`secondary`, `secondary_hov`, `btn_secondary_text`, `progress_idle`, `progress_proc`,
`progress_done`, `progress_err`, `menu_bg`, `menu_fg`, `menu_active_bg`

#### Storage en `AppSettings`

```python
active_palette: str = "Default Dark"           # nombre de la paleta activa
palette_overrides: dict[str, str] = field(default_factory=dict)  # {token: hex_value}
```

`palette_overrides` contiene solo los tokens que el usuario modificó. Al resolver `p(key)`:
1. Buscar en `palette_overrides` primero.
2. Si no hay override, usar la paleta activa de `_PALETTES`.
3. Fallback a `_PALETTES["Dark"]` si el nombre no existe.

#### UI del Panel de Paletas

- **Panel separado** (similar a `_settings_frame`) con su propio `CTkFrame`.
- Acceso: Settings menu → "Color Palette…" → oculta tabview, muestra palette panel.
- Layout:
  - Dropdown "Active palette" (6 opciones) — al cambiar, aplica inmediatamente a preview.
  - Grid de swatches: label del token + swatch (CTkButton de 36x28) — click abre `colorchooser`.
  - Botones: "Reset to palette defaults" (resetea overrides del modo actual) + "Save" + "Back".
- Al seleccionar nueva paleta del dropdown, si es de modo opuesto (Dark↔Light) preguntar o forzar el appearance mode correspondiente. El agente decide la lógica de modo.

#### Cambio de `p()` para soportar overrides

`p()` en `theme.py` debe consultar `_active_overrides` (dict global mutable):
```python
_active_overrides: dict[str, str] = {}

def set_palette_overrides(overrides: dict[str, str]) -> None:
    _active_overrides.clear()
    _active_overrides.update(overrides)

def p(key: str) -> str:
    if key in _active_overrides:
        return _active_overrides[key]
    mode = ctk.get_appearance_mode()
    return _PALETTES.get(mode, _PALETTES["Dark"]).get(key, "#FF0000")
```

`set_palette_overrides()` se llama al iniciar la app (desde `_apply_startup_settings`) y al guardar el panel de paletas.

#### Localización

Nuevas claves en `locale.py`:
- `"menu_color_palette"` → "Color Palette…" / "Paleta de colores…"
- `"palette_header"` → "Color Palette" / "Paleta de colores"
- `"palette_active_lbl"` → "Active palette:" / "Paleta activa:"
- `"palette_reset_btn"` → "Reset to defaults" / "Restablecer"
- `"palette_save_btn"` → "Save" / "Guardar"
- `"palette_back_btn"` → "Back" / "Volver"
- Claves para cada nombre de token (legibles): `"token_bg"`, `"token_surface"`, etc.

### D-07: Console Log i18n

**Scope:** Todos los tabs (1-6 + Tab 2).

**Enfoque:** Mensajes de estado/usuario pasan por `s()`. Datos técnicos (paths de archivo, nombres de modelo, códigos de error HTTP) permanecen en inglés inline.

**Ejemplo:**
```python
# Antes:
self._log_to(tb, "⚠️ Please select an input video file.")
# Después:
self._log_to(tb, s("log_warn_no_input_video"))
```

```python
# Datos técnicos mantienen inglés:
self._log_to(tb, f"{s('log_prefill_tab4')}: {extracted.name}")
```

**Nuevas claves de locale necesarias** (el agente completa la lista en PLAN):
- Advertencias: `log_warn_no_input_video`, `log_warn_no_input_audio`, `log_warn_no_input_subtitle`, `log_warn_not_wav`, `log_warn_no_output_dir`, `log_warn_output_not_wav`, `log_warn_no_target_lang`, `log_warn_no_input_transcription`, `log_warn_no_input_file`, `log_warn_file_not_found`
- Progreso: `log_running_step`, `log_step_success_extract`, `log_step_success_transcribe`, `log_step_success_translate`, `log_step_success_write`
- Pre-fill: `log_prefill_tab4`, `log_prefill_tab5`, `log_prefill_tab6`
- Errores: `log_error_extract`, `log_error_transcribe`, `log_error_translate`, `log_error_write`, `log_error_cannot_apply_output_name`
- Separador: `log_separator` → `"═" * 50`

**Traducciones en `es`** para todas las claves anteriores.
