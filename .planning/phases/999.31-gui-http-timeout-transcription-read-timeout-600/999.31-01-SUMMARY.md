# Phase 999.31: GUI HTTP Timeout — Transcription Read Timeout Fix

**Fixed `ReadTimeout` crash by replacing flat `timeout=600` with split `timeout=(5, None)` in `_run_step_in_bg`, allowing transcription of arbitrarily long videos while keeping fast server-down detection.**

## What Changed

Single-line change in `gensubtitles/gui/main.py`, `_run_step_in_bg._worker()`:

```python
# Before
resp = req.post(f"{server.BASE_URL}{api_endpoint}", json=payload, timeout=600)

# After
resp = req.post(f"{server.BASE_URL}{api_endpoint}", json=payload, timeout=(5, None))
```

- `5` = connect timeout: raises quickly if the local API server is not running
- `None` = no read timeout: allows `/steps/transcribe` to run as long as Whisper needs

All four stepper tabs (Extract, Transcribe, Translate, Write SRT) share `_run_step_in_bg` and benefit from this fix.
